## Ganjoor poetry data

The `data/` directory contains the [Ganjoor public poetry export](https://github.com/ganjoor/ganjoor-data), generated from [GanjoorService](https://github.com/ganjoor/GanjoorService). The export's original [README](data/README.md) and [API documentation](data/API.md) are retained with it. See [SOURCES.md](SOURCES.md) for the snapshot identifier.

No license file or explicit data license was included with this export. GanjoorService's GPL license covers its software and is not presented here as a license for the poetry data. Redistribution terms for the complete data export need to be confirmed before it is included in published application packages.
